1 Verbindung nicht verbunden

Wird nur in diesem Browser gespeichert und ausschließlich an api.github.com gesendet.

Wie bekomme ich ein Token?

1. Öffne Fine-grained Token anlegen
2. Bei Repository access dieses Repository auswählen
3. Bei Permissions → Repository permissions setzen:
  • Contents: Read and write
  • Actions: Read and write
4. Token erzeugen und hier einfügen

2 Deine App-Dateien

Dateien hierher ziehen
oder unten auswählen — index.html muss dabei sein

    Noch nichts ausgewählt — dann bleiben die bisherigen Dateien im Repository unverändert.

    3 Angaben zur App

    Eindeutige Kennung. Kleinbuchstaben, mindestens ein Punkt, keine Leerzeichen oder Umlaute.

    Ohne Auswahl bleibt das bisherige Icon erhalten.

    4 App bauen

    Die Weitergabe-Variante ist kleiner und für den Play Store geeignet. Sie setzt voraus, dass die vier Keystore-Secrets hinterlegt sind (siehe docs/CI.md).
